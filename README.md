# Secret Santa discord bot

## Features

- Organize your secret santa fully anonymously, so no one in the group will know who you are the secret santa of
- Making a wishlist of items so your secret santa can have an easy time(Not mandatory but it will allocate the space for the data in the db)
- Asking anonymouse questions to the person you are the secret santa of (maybe, but for sure not the other way around)
- Giving updates on where and when a package will arrive
- Each participant can list up to 5 locations (with priority) of where to send the gift and at what name
